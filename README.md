# Bangla Bubble Pop

A fun educational game for kids to learn Bangla alphabets by matching them with their corresponding English sounds. Bubbles float up from the bottom of the screen containing either Bangla letters or their phonetic sounds in English. Match them before they float away!

## Game Rules

1. Bubbles containing Bangla letters and their English sounds will float up from the bottom of the screen
2. Click on a Bangla letter bubble and then its corresponding English sound bubble to make a match
3. When you make a correct match, the bubbles will pop and fall to the grass, and you'll score a point
4. If bubbles float off the screen before you can match them, you'll miss the opportunity to score
5. Try to match as many pairs as you can!

## Setup and Installation

1. Make sure you have Node.js installed on your computer
2. Clone this repository
3. Install dependencies:
```bash
npm install
```
4. Start the development server:
```bash
npm start
```
5. Open your browser and navigate to `http://localhost:3000`

## Technologies Used

To build the project for production:
```bash
npm run build
```

To preview the production build:
